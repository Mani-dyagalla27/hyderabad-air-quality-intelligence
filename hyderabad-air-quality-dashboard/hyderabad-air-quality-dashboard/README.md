# Hyderabad Air Quality Analytics Dashboard

An interactive Streamlit dashboard built around real public air-quality measurements from monitoring locations within 25 km of Hyderabad.

## Research questions
1. How do measured pollutant concentrations change over time?
2. Which pollutants and monitoring stations show higher average readings?
3. Do monthly patterns suggest seasonal variation in the observed measurements?

## Data source and integrity
- Source: OpenAQ API v3, which aggregates publicly accessible ground-level air-quality measurements.
- Coverage: Hyderabad area, within a 25 km radius of central Hyderabad.
- Period requested by the downloader: 1 January 2024 through yesterday (local machine date).
- Granularity: daily aggregated sensor readings.
- The downloader does not fill, interpolate, or invent missing observations.
- Values remain in their reported units. The dashboard does not label concentration measurements as AQI.
- OpenAQ data attribution/licensing varies by upstream provider. Retain provider/owner fields and review the applicable source licence before redistribution.

OpenAQ API documentation: https://docs.openaq.org/
OpenAQ data and usage: https://openaq.org/

## Setup (Windows PowerShell)
```powershell
py -m venv .venv
.\.venv\Scripts\Activate.ps1
python -m pip install -r requirements.txt
python fetch_data.py
streamlit run app.py
```

The fetcher asks for your OpenAQ API key without displaying it. Create an API key through OpenAQ. Do not commit the key to GitHub.

## Setup (macOS/Linux)
```bash
python3 -m venv .venv
source .venv/bin/activate
python -m pip install -r requirements.txt
python fetch_data.py
streamlit run app.py
```

## Dashboard features
- Date, pollutant and station filters
- KPI summary
- Daily pollutant trends
- Mean concentration comparison by pollutant
- Month-of-year profile
- Monitoring-station comparison
- Filtered CSV download
- Data quality and source transparency notes

## Data file schema
`data/hyderabad_air_quality.csv` is generated by `fetch_data.py`. It includes:
`date, city, location, location_id, sensor_id, parameter, value, unit, latitude, longitude, provider, owner`.

## Publish a live link
1. Push this project to your own GitHub repository (do not commit your API key).
2. Create a Streamlit Community Cloud app and select `app.py` as the entry point.
3. Add the generated dataset to the repository only if its licence permits redistribution and file size is appropriate. Otherwise, use an approved private storage/data workflow and modify the app to load it securely.
4. Open the deployed URL in a private browser window and verify the charts and filters.

For a self-running local copy, share the project folder/ZIP and the setup steps above. The recipient needs Python and internet access for the initial dataset download.
